# Campus Complaint Management System

A cloud-based campus complaint management system built using AWS.

## Features
- Student and administrator authentication
- Complaint submission and tracking
- Complaint data storage using Amazon DynamoDB
- Serverless backend using AWS Lambda and API Gateway
- Email notifications using Amazon SNS
- Static website hosting using Amazon S3

## Technologies Used
- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB
- Amazon Cognito
- Amazon SNS
- Amazon S3
- HTML, CSS, and JavaScript

## Project Purpose
This project helps students submit and track campus complaints while enabling administrators to manage complaints efficiently.
